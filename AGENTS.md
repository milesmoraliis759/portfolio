# Portfolio repository instructions

For UI, interaction, accessibility, reading layout, navigation and Next.js performance work, use .agents/skills/pharma-portfolio-ux/SKILL.md.

Treat the site as a beginner-friendly B.Pharm learning notebook. Keep the main navigation focused on major destinations. Prefer statically generated lesson/article routes and small client-side interactive islands; do not introduce request-time rendering without a clear per-request need.

For pharmacy content authored in this repository, use the content-writer skill in the companion milesmoraliis759/content repository. Preserve the distinction between lesson quizzes, original Practice Questions, mock tests and verified PYQs.

Run lint, typecheck and build checks before opening a PR. Report only tests and visual checks actually completed.
